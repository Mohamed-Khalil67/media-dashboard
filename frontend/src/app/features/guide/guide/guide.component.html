Platform Setup Guide

Follow these steps to create your Facebook or Shopify developer app before connecting.

📘 Facebook Ads 🛒 Shopify

📘 Facebook Ads Setup

1

Create the app

  1. Go to developers.facebook.com → My Apps → Create App
  2. Select app type: Business — this is the only type with Marketing API access. Cannot be changed later.
  3. Enter an app name (e.g. My Media Dashboard) and your contact email
  4. Click Create App
2

Add Facebook Login product

  1. On the app dashboard → Add Product → find Facebook Login → click Set Up
  2. Choose Web as the platform
  3. Enter your site URL and click Save
  4. Go to Facebook Login → Settings
  5. Under Valid OAuth Redirect URIs add your callback URL exactly as shown in the connect modal
  6. Enable Enforce HTTPS
  7. Click Save Changes
3

Add Marketing API product

  1. Dashboard → Add Product → find Marketing API → click Set Up
  2. This unlocks ads_read and ads_management permissions needed to pull campaign data
4

Configure Basic Settings

  1. App Settings → Basic
  2. App Domains: enter your domain (no https://, just the hostname)
  3. Add a Privacy Policy URL — required to go Live
  4. Click Save Changes
  5. Copy your App ID and App Secret (click Show next to the secret)
5

Switch app to Live

  1. Top of the dashboard → toggle from In development to Live
  2. Confirm the switch
If you skip this step, only your own Facebook account can connect. All other users will be blocked.

🛒 Shopify Setup

1

Create the app

  1. Go to dev.shopify.com/dashboard → Apps section
  2. Click Create app → select Start from Dev Dashboard
  3. Enter your app name → confirm
2

Configure app version

  1. Go to the Versions tab
  2. Fill in:
    • App URL: your dashboard URL
    • Allowed redirect URLs: your callback URL exactly as shown in the connect modal
    • Scopes: read_orders,read_analytics,read_products
    • Webhooks API version: select the latest available
  3. Click Release
3

Install on your store

  1. App Home section → Install app
  2. Choose your Shopify store → confirm installation
The store must have your app installed before OAuth will work. Shopify will reject the connection otherwise.
4

Get credentials

  1. App → Settings tab
  2. Copy your Client ID and Client Secret
